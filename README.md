# London Airbnb Price Prediction

Coursework 1 for 6COSC017C-n Machine Learning and Data Analytics.

The project predicts the nightly price of Airbnb listings in London.

## Data

Inside Airbnb, London detailed listings: https://insideairbnb.com/get-the-data/

Download `listings.csv.gz`, unzip it and save it as `data/listings.csv`.
